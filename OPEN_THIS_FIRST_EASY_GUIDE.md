## ❓ TROUBLESHOOTING:

- **Browser says "can't connect":** Make sure the START.bat / START.command window is still open (that's the server).
- **Forgot password:** Open the file `arbiter/data/customers.json` — that's where everything is stored.
- **Stop the server:** Go back to the black window and press Ctrl+C, or just close it.
